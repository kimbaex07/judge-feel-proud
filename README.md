A tiny pure-Python program that writes one short family scene — warm, funny and heartfelt, two lines and under 280 characters — to `/output/entry.txt` for make.fun's "Make the AI Judge Feel Proud: A Family Scene" bounty. No third-party imports, no network, no randomness: the same scene is written on every run.

## How it works

`main.py` holds the scene as a single constant and writes it to `/output/entry.txt` (creating `/output` if needed), then sets the file mode to `0644`. The scene is a small domestic moment: Dad fixes the wobbly kitchen table and declares himself "load-bearing Dad", and Mum laughs so hard she snorts her tea.

## Run it

```sh
python3 main.py
```
